# Internet avatar sources

These bundled avatars were downloaded from the official DiceBear HTTP API and
rasterized to 1024 × 1024 PNG for Nodalix. Each uses a fixed seed, so the source
is reproducible. The selected DiceBear styles are released under CC0 1.0.
