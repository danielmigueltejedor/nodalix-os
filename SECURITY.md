# Security policy

Please report a vulnerability in Nodalix OS (its installer, updater, NxPM, Nodalix Shell, the
signed kernel or the package repository) privately through
[GitHub private vulnerability reporting](https://github.com/getnodalia/nodalix-os/security/advisories/new),
not in a public issue or pull request. Say which release you run and how to reproduce the problem.

Nodalia maintains Nodalix OS and handles every report. A problem in an upstream package (Arch
Linux, GNOME, the Linux kernel) belongs to that project; tell us too if Nodalix OS ships it in a
way that makes it worse.
