# Nodalix OS 0.4.0

This release adds a unified Applications folder, native storage management, and
improvements to the GNOME desktop, updates and Phone Link. The
[issue audit](../preparation-0.4.0.md) tracks remaining work and validation.

- Active Phone Link calls stay first in the native GNOME notification history, retain their Answer/Decline/Hang up actions and cannot be dismissed by Clear all while live.
- Calendar and notification history have a shared monitor-relative height limit, independent of Phone Link. Long lists scroll natively, the footer stays reachable and empty lists shrink.
- Tiling Assistant is retained with user preferences; an earlier development-candidate removal is repaired. Optional automatic tiling preserves manually tiled windows.
- Multi Monitor Bar mirrors the GNOME panel on secondary monitors; the primary panel keeps its native layout. Blur My Shell supplies all panel, menu and dock blur. Obsolete replacement bars and shortcut extensions are archived with recoverable backups.
- Animated wallpaper supplies the complete monitor image underneath the panel, including its top 32 pixels. This fixes coloured strips and blurred copies of panel text without changing GNOME or Blur My Shell shaders. Static and dynamic blur are exercised together with live wallpaper on both monitors.
- Calendar agenda height is enforced on the native scroll viewport, including events arriving while open, with the same compact limit on every monitor even when Phone Link is disabled. Blur My Shell 77 is the unmodified official extension; its migration removes legacy manual corner effects.
- App folders recognize current and future ArtCraft tools by publisher namespace and suite metadata. Apps appear in ArtCraft and their purpose folder at the same time: CADCraft/SolidCraft in Engineering, document tools in Office and graphics tools in Multimedia. Custom folders are preserved. Obsolete organizer prototypes are backed up and retired, and supplied icons resolve for TextureCraft, Craft Anything and future tools.
- The Applications folder has a themed icon and shows the installed desktop apps with their own icons. Open AppImage, Flatpak and Arch package installers from Files or put them in Applications. Send a managed app to Trash to uninstall it through its provider, retaining personal data. Essential system components are protected; Steam manages its own game removals.
- Settings → Applications → Storage displays capacity and applications ordered by size, large documents, music, photos/video, downloads and development tools. View items in Files or confirm sending them to Trash. Storage is measured on demand.
- Search for Storage, Updates, System Diagnostics, Nodalix OS Version, LocalSend or Animated Wallpapers in the GNOME launcher to open the corresponding Settings section. Applications is created automatically if the account does not have it.
- Flatpak checks and updates use only the origins of installed apps and components. An unrelated broken repository no longer blocks other updates. A repair action completes legacy partial automatic schedules; local bundles without a repository are identified separately.
- About shows the installed Nodalix OS version and refreshes when it changes. Update statuses use readable language, and a busy system package manager is retried automatically.
- Phone Link can dial numbers from GNOME Contacts. Bluetooth notification preparation registers the advertisement asynchronously, restores address resolution for paired iPhones, and presents the correct hands-free device class for iOS permissions.
- Dock blur tracks the background allocation and startup translations so its first visible background matches the icons without a hide/show workaround.
- Auto Tiling defaults to four windows and splits the largest available region so four windows form quarters while respecting gaps and client size constraints.
- GNOME native shortcuts restore Super+C/V, Super+Shift+3/4 screenshots, Super+Enter terminal, Super+B browser, Super+M mail and Super+Q closing the focused window. Focus follows the pointer without a click or automatic raise. Known dock/keyd factory conflicts (including dock overlay on Super+Q) are migrated without removing custom mappings. See [the shortcut reference](../shortcuts-0.4.0.md).
- Ghostty opens with the new blue-to-turquoise Nodalix ASCII logo and a live system card showing the installed version, architecture, kernel, uptime, memory and root disk use. Smaller windows use the compact artwork and stack the details when needed. The upgrade replaces the known legacy Arch greeting.
- Animated backgrounds negotiate native DMA-BUF import where supported, retain compatible GL/system-memory playback, skip a full-screen shader for rectangular desktop clipping and reuse cached panel blur. A debounced window-coverage policy pauses playback behind tiled windows and resumes when the desktop is revealed. Original video resolution, quality and frame rate are preserved. Hardware 4K30, software decode, two-monitor motion and Overview rounding are verified on this PC; savings on other hardware still require measurement.
- Updates uses a native symbolic refresh icon and adds independent automatic Nodalix, system, Flatpak and firmware switches. Authorization is requested when enabling; subsequent scheduled updates need no password, and the authorizing user can disable without a prompt. No password is stored and the PC never reboots automatically. See [automatic updates](../automatic-updates.md).
- Native Updates reports a damaged or missing Nodalix identity, retains a private bounded operation log across service restarts, displays available package versions and requests reboot based on actual critical package changes.
- Authenticated system updates check the package-manager lock, free space and critical battery level, verify the package database afterward and use opt-in pre-update Btrfs protection with bounded retention.
- System Settings gains a local diagnostics page and an opt-in command for resource samples. Reports omit account names, device identifiers, process arguments and personal content; unavailable power and VRR measurements stay unavailable.
- The desktop enables Global Menu and Rounded Window Corners by default, alongside Blur My Shell, Multi Monitor Bar and Tiling Assistant. Upgrades restore the two extensions if an earlier development candidate disabled them. Global Menu rejects menu responses for a previously focused window. Shortcut-generated and generic fallback menus are disabled by default; explicit user preferences remain configurable.
- A capped ZRAM vendor default preserves administrator overrides and disk swap. Layout maintenance follows filesystem events with a slower reconciliation fallback, and unconfigured iCloud mounts skip startup instead of repeatedly failing.

Phone notifications require the iPhone to grant sharing permission and expose its
Bluetooth Low Energy notification service. The storage inventory focuses on
personal folders and known developer caches; reported app sizes can exclude
shared runtimes or be unavailable for an external provider. See the audit for
remaining hardware and application coverage.
