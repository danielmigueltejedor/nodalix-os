# Nodalix OS 0.6.1

A polish release on top of 0.6.0: Archivador feels finished, Settings decides the
style on its own, Brújula jumps from 0.3 to 0.6 and the Store learns about the
Nodalia apps.

- **Archivador** has a new selection model. Drawing a box marks what it touches
  while you draw it, a click on an empty part clears the selection, and a drag
  carries everything that was selected. Selected files get an accent outline,
  the selection box is translucent, and the grid cells are smaller.
- **Archivador folders and cloud**: folders are flat and quieter (Adwaita-shaped,
  two tones), every cloud service has its own icon, also in Favorites, and the
  sidebar names and icons of Archivador and Settings are slightly larger.
- **Recent** in Archivador shows the newest 200 files and no longer lists files
  on GVfs mounts. Video thumbnails need `ffmpegthumbnailer`, now a dependency.
- **Settings** offers Light and Dark only in Appearance. GNOME's "default" means
  no preference and every app drew it light, so an old "default" is saved as
  light when Settings starts.
- **Brújula 0.6.0** (was 0.3.0): passkeys with the phone (QR code and Bluetooth),
  the Spotlight on every new tab, 2FA codes in the password manager, importing
  history, cookies and passwords from other browsers, drag-to-reorder tabs and
  essentials, real fullscreen video, safer downloads and updates inside the
  AppImage.
- **Store** has a Nodalia view to install and update the Nodalia apps (Brújula,
  Vortia, Forja, Lienzo, Vinilo) through NXPM, and the NXPM catalogue lists them.
- **Updates**: the project now lives in the `getnodalia` organisation. The
  updater and Settings > Updates look for releases there directly, and an
  installation that still names the old repository in
  `/etc/nodalix/updater.json` is pointed at the new one, instead of depending on
  GitHub redirecting the old name.
- Developer tools can install the native apps of a checkout over the installed
  ones to try a change on the real system.
