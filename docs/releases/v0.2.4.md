# Nodalix OS 0.2.4

Esta actualización continúa puliendo la experiencia visual y la integración del sistema.

## Mejoras destacadas

- Se restaura la apariencia translúcida de Ajustes para mantenerla coherente con el resto de la shell.
- Se eliminan bordes decorativos innecesarios en la interfaz principal de Ajustes.
- Almacenamiento vuelve a mostrar el espacio libre dentro de la barra de uso del disco.
- Las categorías de almacenamiento utilizan colores más diferenciados para mejorar la legibilidad.
- Se integran en el empaquetado las mejoras de sincronización de iCloud Drive y calendario.

- Se integra el calendario de Nodalix con Evolution Data Server y sincronización bidireccional con GNOME Calendar e iCloud.
- Los eventos personales pueden crearse, editarse y eliminarse directamente desde el calendario de la shell.
- Se rediseñan los sliders de la shell con una estética horizontal, gruesa y sin thumb, compartida entre volumen, brillo y Ajustes.

## Correcciones

- Se corrige la validación de ownership del test real de actualización para consultar correctamente el root temporal de pacman.
