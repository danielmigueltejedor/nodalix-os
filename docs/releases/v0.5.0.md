# Nodalix OS 0.5.0

This release moves Nodalix to its own managed stack: the Nodalix Shell, the
Nodalix kernel, icons and cursor from Nodalix's own icon-theme repository, and
the Nodalix Store as the default store. It also reduces background work in the
Steam integrations.

- The generic x86-64 Nodalix kernel builds from a pinned CachyOS revision.
  Integrity lockdown is enabled, kernel modules are signed during the build,
  and xpadneo is built in with the Nodalix Bluetooth identity fix.
- The kernel package is distributed through Nodalix releases. The updater
  verifies the release signature before accepting a kernel download. An Arch
  recovery kernel stays available during the transition.
- The Steam launcher helper queries XWayland window properties over one
  connection and reuses process lookups for multiple windows. The GameMode
  detector avoids parsing complete environments for unrelated processes.
  A 40-window X11 fixture removed 205 subprocess launches across five
  synchronizations. In a local 533-process sample, 30 detector scans took
  120 ms of CPU time compared with 510 ms before the change.
- GNOME launcher searches in Zen and Firefox open a new tab in the existing
  window for supported default search engines. Other engines continue to use
  the browser’s own search command. Web search lives in the GNOME Overview
  and the separate Search the Web launcher has been retired.

- Appearance can import MP4, WebM and MKV files into the user's animated
  wallpaper library. It refreshes as thumbnails are generated, reports
  identical files, and can remove personal duplicates after confirmation.
  Search, filters, favorites, technical details and an on-demand preview
  are available in the same gallery.
- Changing an animated wallpaper preserves Hanabi preferences. The pause and
  graphics settings are available in Appearance. The optional 60 FPS action
  creates a separate copy and can be cancelled.
- The Nodalix cursor uses real files in the system icon directory. GNOME
  prepares user copies for Steam's runtime when Nodalix is selected and
  keeps personal cursor themes.
- The optional Nodalix Shell preview bundles the dock, multimonitor panels,
  Blur My Shell, Tiling Assistant, the global menu, rounded corners, and
  Nodalix's cursor and automatic tiling modules. The development build also
  integrates Hanabi, LocalSend, Now Playing Card and the greeter background.
  The same GNOME preferences apply after the upgrade and after rolling back.
- Application icons and the current Capitaine cursor sources are maintained
  in Nodalix's own icon-theme repository. Both packages verify the same pinned
  revision. Craft, ArtCraft Launcher, SolidCraft, Audacity 4 Portable, LACT
  and The Witcher 3 include the existing custom artwork. Known generated
  copies are adopted while personal icon edits are preserved.
- Nodalix Shell incluye el perfil de escritorio de referencia: tema oscuro con
  acento amarillo, huecos de mosaico de 8 px, menú global, paneles de varios
  monitores, Now Playing Card centrada y desenfoque del panel, el dock y los
  menús. Las preferencias que ya tengas definidas no se modifican.
- Nodalix Store is the default store and ships with the system. It installs and
  updates Flatpak applications with its own Flatpak backend, uses Nodalix
  Package Manager for system updates, and handles `appstream:` and Flatpak
  links by default.
- Nodalix Package Manager (`nodalix-nxpm`) manages system packages through
  pacman with authorization from Polkit. It runs full system upgrades only,
  does not install or update single official packages, and has AUR support
  disabled.
- Nodalix packages are signed in a `[nodalix]` pacman repository. The new
  `nodalix-keyring` package installs the repository's public key
  (`3DE029728CDE1828E18B437930D356AC0F6AB1CF`) so that pacman can verify
  every package and the repository database.
