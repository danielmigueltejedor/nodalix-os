# Nodalix OS 0.5.0

This release prepares the Nodalix kernel and reduces background work in the
Steam integrations.

- The generic x86-64 Nodalix kernel builds from a pinned CachyOS revision.
  Integrity lockdown is enabled, kernel modules are signed during the build,
  and xpadneo is built in with the Nodalix Bluetooth identity fix.
- The kernel package is distributed through Nodalix releases. The updater
  verifies the release signature before accepting a kernel download. An Arch
  recovery kernel stays available during the transition.
- The Steam launcher helper queries XWayland window properties over one
  connection and reuses process lookups for multiple windows. The GameMode
  detector avoids parsing complete environments for unrelated processes.
  A 40-window X11 fixture removed 205 subprocess launches across five
  synchronizations. In a local 533-process sample, 30 detector scans took
  120 ms of CPU time compared with 510 ms before the change.
- GNOME launcher searches in Zen and Firefox use the browser profile’s default engine.
