# Nodalix OS 0.2.0

Primera versión estable de la línea 0.2.0.

- El launcher ocupa el ancho completo de la barra en modo escritorio. Las columnas se adaptan al espacio disponible y ambos comparten una superficie continua, con la barra fija durante la animación.
- Modo Ventanas, mosaico y navegación horizontal; minimización compartida entre la barra y las aplicaciones compatibles.
- Galería de fondos estáticos y animados con un motor unificado, vista previa y favoritos.
- Organización localizada de carpetas, integración de iconos Colloid y actualizaciones de sistema desde Nodalix.
- Enlace móvil mantiene notificaciones, mensajes y contactos cuando las llamadas HFP/oFono o la publicidad Bluetooth no están disponibles.
- ISO x86_64 con sesión de prueba y perfil de instalación Nodalix sobre Archinstall. La instalación necesita Internet, permite revisar discos/cifrado/usuario y conserva un kernel de recuperación. El perfil de hardware utiliza una base compatible en máquinas virtuales y equipos antiguos; ofrece optimización CachyOS en CPU compatibles.

La cobertura de validación de la ISO, sus requisitos y limitaciones se documentan en `docs/iso.md`. Las imágenes no incluyen credenciales, datos personales ni aplicaciones con licencias particulares.
