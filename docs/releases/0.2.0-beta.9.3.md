# Nodalix OS 0.2.0-beta.9.3

- Minimizar desde la cabecera de una aplicación usa la misma ocultación en segundo plano que el dock. Se añade un adaptador para Wayland y XWayland porque Hyprland 0.56.2 no expone estas peticiones a Lua. Solo se carga cuando coincide exactamente la compilación del compositor.
- La barra inferior se une al marco, sin separación ni contorno. El lanzador crece desde ella con la curva de animación de los paneles superiores y mantiene el contenido durante el cierre.
- El selector lateral de fondos pasa a ser una galería adaptable con búsqueda, filtros de estáticos/animados/favoritos, selección para previsualizar y confirmación para aplicar. Se puede recorrer con las flechas y cerrar con Escape; cerrar cancela cualquier previsualización pendiente.
- El proceso de publicación incluye únicamente los paquetes finales, sin duplicar los archivos de origen de Skwd.

Validación: 142 pruebas automatizadas, compilación del adaptador contra Hyprland instalado, prueba real de minimizar desde una ventana GTK y restaurarla, carga de QML y revisión visual del dock, lanzador y galería.

Conserva las mejoras de beta.9.2 en fondos, bloqueo, organización, iconos y Enlace móvil.
