- **Phone Link is substantially more resilient.** Bluetooth LE and BR/EDR are now tracked independently, allowing notification connectivity to recover without unnecessarily interrupting calls or classic Bluetooth services.

- **ANCS recovers automatically after Bluetooth LE interruptions.** Notification subscriptions are rebuilt when LE returns, while stale D-Bus listeners are cleaned up to prevent duplicate notification delivery.

- **iPhone call integration is more reliable.** HFP and oFono modem recovery now retry automatically after transient Bluetooth failures instead of remaining offline.

- **Bluetooth preparation is handled by Nodalix.** Required BlueZ experimental support and address-resolution behaviour for compatible paired iPhones are configured by system services instead of relying on manual setup.

- **Phone Link now has a safe packaged migration path.** Existing pairing configuration is preserved while the legacy user installation is replaced, with rollback protection if the packaged service fails to start.
