# Nodalix OS 0.2.0 Beta 7

Esta revisión refina Ajustes después del estreno de la Beta 6.

- Las actualizaciones de Nodalix viven únicamente en su página dedicada. La
  página general queda reservada para Arch, aplicaciones, firmware y sus
  automatizaciones.
- La actualización automática de Nodalix se configura ahora junto al canal
  estable o beta, evitando controles duplicados.
- La detección de GPU utiliza una consulta compatible con la ejecución QML y
  muestra correctamente la gráfica dedicada en Información del sistema.
- El perfil CachyOS realiza una actualización completa y coherente de Arch
  antes de instalar el kernel optimizado, conservando el kernel Arch como
  alternativa de arranque.
- La shell y los servicios de sesión ya no se habilitan globalmente para el
  usuario interno del greeter. Así se evita que aparezca una segunda shell sin
  fondo en otro monitor antes de iniciar sesión.
- El selector de imagen de perfil libera el foco exclusivo de Ajustes antes de
  abrirse y recupera después la misma página, evitando el bloqueo entre ambas
  ventanas.
