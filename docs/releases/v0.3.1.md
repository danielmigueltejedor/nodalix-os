# Nodalix OS 0.3.1

Development preparation; this version has not been published.

- GNOME 51 keeps its native session, GDM, portals and desktop controls, with the installed Dash to Dock 110 source and an extension that clears startup feedback after an application has shown its main window.
- Steam games gain offline desktop launcher and icon synchronisation, native window association and optional automatic GameMode requests for running game executables.
- Craft applications gain persistent native window controls and a portable launcher that preserves original commands and file arguments.
- A separate first-login migration adopts the packaged services from the local prototypes, retains backups and respects explicitly disabled extensions.
- Package metadata, candidate validation and the GNOME update bridge prepare the 0.3.1 package set without requiring a release tag or publishing artifacts.
