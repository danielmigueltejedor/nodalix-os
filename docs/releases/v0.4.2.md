# Nodalix OS 0.4.2

This maintenance release delivers the Nodalix release public key to installed
systems. It prepares the updater to verify signed releases, including the
signed kernel planned for Nodalix OS 0.5.0.

- Nodalix Updater installs the release public key at
  `/usr/share/nodalix/keys/release.pub`. The updater uses it to verify the
  signature of future release manifests.
- Nothing else changes. The update flow, schedules and component versions
  stay as in 0.4.1, and this release is not signed itself.
