# Nodalix OS 0.4.1

This maintenance release cuts desktop background work and improves pointer
visibility and Xbox Bluetooth controller support.

- Craft window integration reacts to X11 events and combines nearby application
  changes. A slower safety check still catches applications that are late to
  report their window class.
- The application icon service reacts to desktop-entry changes, keeps its
  periodic reconciliation as a fallback and leaves identical files untouched.
- Steam reuses its generated launcher icons while their source images stay the
  same. A session with no installed Steam games skips the X11 window scan.
- The GNOME sign-in screen and new desktop accounts use Nodalix Capitaine
  Cursors at 30 pixels. The sign-in screen has its own setting so earlier
  greeter cursor preferences do not take precedence.
- Shaking the pointer draws the Capitaine arrow from SVG artwork at the larger
  size. The arrow follows the pointer across monitors and shrinks after fast
  motion stops.
- Nodalix packages xpadneo 0.10.5 for supported Xbox Bluetooth controllers.
  The patched driver preserves the native HID identity of Microsoft BLE
  `045E:0B20`. DKMS builds for kernels with matching headers. See
  [Xbox controller support](../xbox-controller.md).
