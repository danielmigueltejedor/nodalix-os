# Nodalix OS 0.2.1

Primera release estable de la rama 0.2.x.

- El launcher mantiene el foco desde la primera apertura incluso al mover el ratón durante la animación.
- La escritura en el buscador permanece inmediata y los resultados usan una cuadrícula virtualizada para reducir el trabajo de renderizado.
- El catálogo de aplicaciones se precalienta de forma diferida para suavizar la primera búsqueda.
- Los iconos funcionales de la shell usan la iconografía nativa de GNOME/Adwaita y se elimina el uso de glifos PUA en la interfaz del sistema.
- Mejoras en LocalSend, favoritos y notificaciones.
- Ajustes de estabilidad y pulido acumulados desde las betas públicas de 0.2.0.

Limitación conocida: tras reiniciar completamente la shell, la primera búsqueda del launcher puede mostrar un pequeño tirón de inicialización; las búsquedas posteriores son fluidas.
