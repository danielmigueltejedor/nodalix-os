# Nodalix Command Bar

Nodalix Command Bar is the main launcher and control surface of Nodalix OS.

## Goal

One fast Spotlight/Raycast-style interface to access apps, files, windows, workspaces, settings, privacy controls, wallpapers, gaming actions, dev tools, Home Assistant and optional AI.

## Default shortcut

- Super + Space

## Initial providers

- Apps from .desktop files
- Quick actions
- Hyprland windows
- Hyprland workspaces
- System actions
- WPE / wallpapers

## Future providers

- Files and recent documents
- Audio devices
- Network and Bluetooth
- Privacy Center
- Gaming tools
- Dev projects
- Home Assistant entities
- AI commands
