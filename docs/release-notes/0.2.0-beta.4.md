# Nodalix OS 0.2.0 Beta 4

Beta 4 convierte la instalación local actual en componentes reproducibles y
actualizables desde GitHub Releases.

## Novedades

- Nueva página **Actualizaciones de Nodalix OS** dentro de Ajustes.
- Detección de versión instalada y disponible mediante Nodalix Updater.
- Selector explícito de canales Estable y Beta.
- Vista de los componentes incluidos, notas y reinicios necesarios.
- Las instalaciones que ya estaban en una beta continúan recibiendo betas,
  incluso si conservaban la configuración antigua del canal estable.
- **Enlace móvil** se distribuye como componente oficial de Nodalix, con su
  servicio, aplicación, icono, reconexión y perfil de audio exclusivo para
  llamadas.
- Instalador remoto verificable para desplegar la release actual en Arch.
- Se conserva el gestor de capas de Beta 3 para que el último popup abierto
  permanezca siempre por encima.

## Privacidad y actualización

Las direcciones de dispositivos, contactos, avisos, cuentas y datos de
emparejamiento no forman parte del paquete. Permanecen en el directorio privado
del usuario. Los cuatro paquetes se instalan en una sola transacción después de
verificar sus SHA-256.

La incorporación de Enlace móvil requiere reiniciar el sistema tras actualizar.
