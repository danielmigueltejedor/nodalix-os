# Nodalix OS 0.5.2

A maintenance release focused on lower background load and a stricter update
chain.

- The updater now refuses any remote release that is not signed with the
  Nodalix release key whenever that key is installed. Before, an unsigned
  manifest could skip the signature check if it did not declare one.
- The Craft desktop helper only starts when a Craft application is installed,
  and starts automatically if one is installed later. It no longer scans running
  processes on every periodic check when nothing needs to change.
- Automatic updates run with lower CPU and disk priority, so they stay out of
  the way while you work or play.
- zram swap no longer stacks zswap compression on top of itself, and swap
  read-ahead is tuned for compressed memory.
- The Steam GameMode helper stops re-reading every process on each scan and
  polls less often while no game is running.
- Dragging a tiled window no longer recomputes the drop preview while the
  pointer is still.
- The package manager service (NXPM) exits after ten idle minutes when it has
  nothing to remember and starts again on demand.
- iCloud Drive logs warnings only, so its log no longer grows with every file.
- The window-layout service can no longer hit systemd's start limit when your
  home folder changes quickly, and the Vinilo updater cleans up correctly when
  paths contain spaces.
