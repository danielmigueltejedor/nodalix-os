# Nodalix OS 0.6.0

The first release where the core apps of the system are Nodalix's own. Settings,
the System Monitor and the file manager are new native apps on the Nodalia
Design Language, the Store is redesigned, and the new Brújula browser is the
default. They replace GNOME Settings, GNOME System Monitor, Nautilus and Bazaar.

- **Settings** is a new native app. It covers appearance and wallpapers
  (including animated ones), Wi-Fi and Ethernet with addresses, DNS, VPN and
  proxy, Bluetooth with the battery of connected devices, displays with
  adaptive refresh rate, sound, notifications, keyboard, mouse, printers, colour
  profiles, online and cloud accounts, users, storage, sharing, updates and
  About. Every page has its own icons.
- **System Monitor** is a new native app with graphs for CPU, memory, network
  and disk, a process list with application icons and a right-click menu, and
  file systems.
- **Archivador** is the new file manager, written from scratch (no longer a
  themed Nautilus). It has favourites, recent files, network places, cloud
  accounts (with rclone), coloured folders, an Applications folder, video and
  PDF thumbnails, drag and drop, and LocalSend sharing built in. It is the
  default file manager: "Show in folder" in browsers, chat and game clients,
  and anything that asks for the file manager, opens it.
- **Brújula 0.3.0** is the new default browser: WebKit, vertical tabs, an ad
  blocker, a password manager, history, private windows, web apps and support
  for Chromium extensions.
- **Store** has a new design on NDL and no longer ships Bazaar.
- Switching between light and dark style is smoother, and changing the accent
  colour no longer makes the desktop hesitate.
- Software that still calls the GNOME tools by name keeps working:
  `gnome-control-center <page>`, `gnome-system-monitor` and `nautilus` open the
  Nodalix apps.
- The ArtCraft launcher is no longer part of Nodalix OS.

Upgrading from 0.5.x replaces `nodalix-control-center`, `nautilus` and
`bazaar` with the new apps in the same transaction.
