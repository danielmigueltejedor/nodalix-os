# Nodalix OS 0.2.0 Beta 5

Beta 5 convierte el escritorio local de referencia en la fuente canónica de
las siguientes versiones de Nodalix. La shell instalada conserva el mismo
comportamiento, apariencia y orden de superposición que el equipo de
desarrollo.

## Novedades

- Se conserva el orden de capas del escritorio local: el último popup abierto
  queda siempre por encima sin cerrar los anteriores.
- Nueva página **Actualizaciones de Nodalix OS** dentro de Ajustes, con canal
  Estable/Beta, componentes, notas, estado y autorización junto a la acción.
- Tareas automáticas independientes para Nodalix, sistema y kernel,
  aplicaciones AUR/Flatpak y firmware.
- Detección fiable de CPU y GPU independientemente del idioma del sistema.
- Microsoft Fluent Emoji sustituye a Blobmoji en la identidad visual.
- Perfil de hardware reproducible para seleccionar repositorios y kernel de
  CachyOS. AMD Zen 4/5 utiliza `cachyos-znver4`; x86-64-v4 y x86-64-v3 usan sus
  repositorios correspondientes.
- `linux-cachyos` se instala como kernel optimizado en equipos de escritorio;
  el kernel Arch `linux` y su entrada de arranque se conservan como respaldo.
- Enlace móvil continúa formando parte del conjunto oficial de Nodalix.

## Seguridad y recuperación

Las descargas de la versión siguen verificándose con SHA-256 antes de una sola
transacción de paquetes. El selector de hardware guarda una copia de
`pacman.conf`, nunca elimina el kernel Arch existente y crea una entrada de
arranque independiente para CachyOS. Los datos privados, emparejamientos y
ajustes del usuario no se incluyen en la versión.
