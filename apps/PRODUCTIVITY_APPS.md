# Productivity Apps

## Vision

The productivity suite should provide native, lightweight tools for documents, spreadsheets, presentations, notes, drawings, and local transfer.

## Apps

- `nodalix-pages`: technical reports and document editing.
- `nodalix-cells`: spreadsheets and unit-aware calculations.
- `nodalix-point`: presentations and PDF export.
- `nodalix-notes`: Markdown notes and project notebooks.
- `nodalix-draw`: vector diagrams and engineering figures.
- `nodalix-drop`: local network file transfer.

## Current status

These apps are scaffolded for planning and future implementation.

## Priorities

1. Define shared document model research.
2. Build `nodalix-notes` first as the smallest useful editor.
3. Reuse Nodalix Files and LocalSend integration for `nodalix-drop`.
