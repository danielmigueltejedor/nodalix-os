# Developer Apps

## Vision

Developer apps help build, package, validate, and debug Nodalix OS components.

## Apps

- `nodalix-devkit`: developer tools and diagnostics.
- `nodalix-bundle-creator`: bundle packaging, validation, preview, and export.

## Current status

`nodalix-bundle-creator` has an initial Rust/GTK skeleton. `nodalix-devkit` is documented scaffolding.

## Priorities

1. Define bundle manifest schema.
2. Add safe validation for local bundle examples.
3. Add export only after validation is reliable.
