# Nodalix Command Bar Design

Visual target:

- Raycast / Spotlight / KRunner inspired launcher
- dark glass container with a 24-32px radius
- purple Nodalix accent
- large central search field
- category chips
- spacious rows with icon well, title, subtitle, and badge
- subtle footer with keyboard hints
- friendly empty state

Functional groups:

- Apps
- Actions
- Windows
- Workspaces
- System
- Web

Ranking direction:

- exact match first
- executable exact/prefix match
- title prefix match
- app names before command text
- future recent/frequent item scoring
