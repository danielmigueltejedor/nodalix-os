# Native App Template

Reference template for Rust + GTK4/libadwaita Nodalix apps.

## Use

Copy this folder, rename the package, update the application id from `os.nodalix.AppName`, and replace the placeholder UI.

## Commands

```bash
scripts/run-dev.sh
scripts/build-release.sh
```

The template intentionally does not include a generator. It is a small, readable baseline for future native apps.
