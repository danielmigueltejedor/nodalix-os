# Nodalix CAD Roadmap

## Stage 0 — Prototype

- UI
- canvas
- grid
- placeholder tools

## Stage 1 — Real 2D sketching

- line
- rectangle
- circle
- layers
- save/open `.nodcad`
- DXF export
- basic DXF import

## Stage 2 — Mesh import and reverse engineering

- STL import
- mesh metadata
- scale factor calculator
- align metadata
- section from mesh
- fit curves
- sketch reconstruction

## Stage 3 — STEP/STP and real CAD geometry

- STEP metadata/reference import
- OpenCascade/OCCT integration research
- optional FreeCAD/OCCT bridge
- B-Rep tessellation
- model tree

## Stage 4 — Technical drawings

- normalized views
- dimensions
- sections
- A3/A4 sheets
- SVG/PDF/DXF export

## Stage 5 — Production CAD features

- constraints
- snaps
- blocks
- assemblies
- parametric modeling
- advanced export/import
