# Additional GNOME 51 extensions for Nodalix 0.3.0

These are the working source snapshots from the GNOME 51 desktop, including local compatibility and Spanish translations. No user settings, credentials or compiled caches are distributed.

- Global Menu: https://github.com/Unmade760/orbit-global-menu, upstream commit `466419282f589be9afe4df6a9d204470fea65ec8`, GPL-3.0. Includes the Python D-Bus companion and the installed compatibility changes.
- Multi Monitor Bar: https://github.com/FrederykAbryan/multi-monitors-bar_fapv2, extension version 56, GPL-3.0. Included as an alternative to the Nodalix secondary bars; they are never enabled together by the default profile.
- Nodalix Auto Tiling: Nodalix GNOME 51 source, GPL-3.0-or-later. The older Tiling Assistant remains available as an alternative.

The login background, Hanabi, rounded corners, Blur my Shell, Dash to Dock, GLocalSend and Nodalix Connect are included by their existing package recipes.
